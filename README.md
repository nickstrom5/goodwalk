# Good Walk

_(Repo folder is `dogwalk/`, the working slug. See `docs/05-naming.md`.)_

**Your dog needs a walk every day. Good Walk makes it a streak.**

An iOS dog-walk streak app built to the same recipe as Clam and Mostly ("30,600 apps" research):
proven market, one-sentence pitch, onboarding that sells, hard paywall, one core loop, shareable
result. Tell it about your dog, see what a dog like yours is built for ("Rex needs about 60 min a
day; the typical dog gets about 23"), then fill the ring around their face every day. Launching for
National Walk Your Dog Week (1–7 Oct 2026), built to peak in Walk Your Dog Month (January).

## What's in the box

| Target | What it is |
|---|---|
| `GoodWalk` | SwiftUI app: 10-step onboarding (dog's name + photo, size, breed type + age, the reveal, target + reminder, first-walk "taste"), StoreKit 2 paywall, home (dog in a progress ring, streak, week bars, totals), walk timer with live distance, quick-log sheet, milestone cards + a totals card with the dog's photo, settings, daily reminder notification with "Walked ✓" / "Start a walk" actions, Siri/Action Button intent |
| `GoodWalkWidgets` | Home Screen widget: the dog's photo in today's ring, minutes vs. target, streak, one-tap "Start a walk" |
| `GoodWalkTests` | Unit tests for the recommendation math, streak/totals, the timer, the mock distance tracker and the seeded pitch numbers |
| `Shared` | App Group constants and the dog-photo store, shared by app and widget |

No backend. Local notifications, StoreKit 2, WidgetKit, App Intents, CoreMotion pedometer,
UserDefaults + two JPEGs in an App Group. No restricted entitlements and no location permission,
so there is nothing to wait for from Apple except review. Analytics events go to the console and,
once a key is set in `GoodWalk/App/Config.swift`, to PostHog (anonymous, no session replay).

## Build

The Xcode project is generated from `project.yml`, so there is no `.xcodeproj` checked in.

```bash
brew install xcodegen
xcodegen generate
open GoodWalk.xcodeproj
```

1. Set your team on the app and widget targets (Signing & Capabilities).
2. Bundle IDs are `app.getgoodwalk.goodwalk` and `app.getgoodwalk.goodwalk.widgets`, matching the getgoodwalk.app domain.
3. **Simulator** runs the whole thing: onboarding, paywall (StoreKit test config), timer, logging,
   milestones, widget. Distance in the simulator comes from the seeded `MockDistanceTracker`;
   a phone uses the pedometer. Notification actions work but fire more reliably on a device.
4. The `GoodWalk` scheme uses `GoodWalk/Resources/Products.storekit`, so the paywall works locally
   without App Store Connect.

Screens: `bash scripts/capture-screenshots.sh "<simulator>"` after installing the app, or run the
`Screenshots` GitHub workflow. Each screen opens with `-screenshot <name>` and seeded data. The
seeded dog is an illustration drawn by `scripts/make-brand.swift`; reshoot App Store screenshots
with a real dog.

## Core loop

```
5:30pm "Has Rex had a walk today?" ──Walked ✓──────▶ usual walk logged, ring fills, streak +1 ──milestone──▶ card ──▶ share
                                   └─Start a walk──▶ timer + distance ──End walk──▶ same
```

## Where the numbers come from

- The guideline is `WalkPlan.recommendedMinutes`: base minutes by size (toy 30, small 40, medium 60,
  large 90, giant 60) × breed-type factor (flat-faced 0.6 … herding 1.5) × age factor (puppy 0.6,
  adult 1.0, senior 0.7), rounded to 5, clamped to 15–120. The bases and breed factors are
  calibrated to the Royal Kennel Club's Breeds A to Z exercise bands (227 breeds) and PDSA's breed
  pages; a unit test pins named breeds to their published band.
- "The typical dog gets about 23" is `WalkPlan.typicalMinutes`: 160 minutes a week, the median
  across 29 studies of owners who walk their dog (Christian et al., 2013), divided by 7. No
  source splits it by dog size, so the app no longer does.
- Every claim, source, exact figure and access date is in `docs/12-sources.md`, including the two
  things still flagged (the puppy/senior ratios are our judgment; Fi's price is second-hand). The
  app presents targets as a general guideline, says "not veterinary advice" wherever they
  appear, and makes no health claims.
- Quick-logged walks estimate distance at 2.0 mph ("dog pace") and are labelled "est.".
- Streak = consecutive days with at least one walk; a day with no walk yet doesn't break it until
  it's over. "Full-target days" are counted separately. Everything is derived in `Stats.compute`.
- Competitor prices in the docs were checked 18 Sep 2026 (sources in `docs/12-sources.md`).

## Status

Builds, unit tests and screenshots all pass in the iOS simulator (Xcode 26.5). Not yet run on a
physical iPhone, so the pedometer path, the notification actions and the widget photo (which needs
a provisioned App Group) are untested on hardware. Next: run onboarding on a device with a real dog
photo, take a real walk with the phone in a pocket, and answer the 5:30pm nudge with "Walked ✓"
without opening the app. If that doesn't feel like magic, fix it before anything else.
